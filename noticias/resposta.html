Introdução ao MVC

O padrão MVC(Model-Views-Controller) é uma arquitetura de software utilizada para desenvolver aplicações que separa a lógica de negócio, a interface do usuário e do controle dos dados.

Conponentes MVC

  • Model(Modelo)-Representa os dados e a lógica de negócio da aplicação.
  • View(Visão)-Responsável pela interface com o usuário e exibição dos dados.
  • Controller(Controle)-Faz a intermediação e comunicaçaõ entre o Model e View
